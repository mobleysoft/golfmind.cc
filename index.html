Pre-shot routine consistency timer

Sports-psychology research on pre-performance routines (Cotterill, 2010, "Pre-performance routines in sport: Current understanding and future directions") links performance under pressure to the timing consistency of a golfer's routine, not just going through the same steps. Time your routine — address to takeaway — below and track how consistent you are round to round, the same real-measurement idea as golfcad.cc's tempo calculator, applied to the mental-game side.

Move your data to another device

This is a real, honest partial answer to the "no cross-device sync" limitation below — not automatic sync, no account or server involved. Export downloads a JSON file with your checklist state, session history, and routine timings; Import reads that same file back in on another device or browser. Importing merges with, and does not overwrite, existing data on this device.

What's real here, what isn't yet

The breathing timer, checklist, session history, and routine-consistency timer above are real, functioning tools — all state persists in your browser between visits, and the consistency score is a real standard-deviation calculation over your own saved timings, not a canned number. What's not built yet: any actual AI-personalized coaching, biometric input (heart-rate, HRV), or automatic cross-device sync (the Export/Import tool above is a real, manual way to move data between devices, but there's no account or server keeping devices in sync automatically — same honest limitation as golflink.cc's ledger, just with a real manual workaround now). This page will be extended honestly as those pieces become real, not described as if they already exist.
